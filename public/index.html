ชั้นเรียน

กำหนด ม./ห้อง แล้วผูกบัญชี LINE ของนักเรียนหรือกลุ่มห้องเข้ากับชั้นเรียน ตารางสอน การแจ้งเตือน และริชเมนูจะแยกตามห้องให้อัตโนมัติ

ผูกบัญชี LINE กับชั้นเรียน

ผู้รับที่เพิ่มเพื่อน OA หรือเชิญบอทเข้ากลุ่มจะขึ้นที่นี่ เลือกชั้นเรียนให้แต่ละบัญชี แล้วริชเมนูของผู้ใช้จะเปลี่ยนเป็นของห้องนั้นทันที

วันพิเศษ

วันหยุดพิเศษ ปิดภาคเรียน และวันกิจกรรม (มีผลทั้งโรงเรียน) ระบบจะงดแจ้งเตือนคาบเรียน แสดง “พรุ่งนี้หยุด” บนริชเมนู และประกาศทุกเช้าในช่วงวันหยุด

ปฏิทิน

รายการวันพิเศษ

📢 ประกาศวันหยุดอัตโนมัติ

ส่งถึงทั้งโรงเรียน: ถ้าโหมดการส่งเป็น Broadcast จะส่งถึงเพื่อนทุกคนและกลุ่ม LINE ทุกกลุ่ม ถ้าเป็นโหมดเลือกผู้รับจะส่งถึงผู้รับที่เปิดไว้ทั้งหมด

ห้องเรียน

ปักหมุดตำแหน่งห้อง เพื่อให้นักเรียนกดนำทางจาก LINE ได้ทันที

เชื่อมต่อ LINE OA

ส่งแจ้งเตือนเป็น Flex Message สวย ๆ พร้อมปุ่มนำทาง

ยังไม่เชื่อมต่อ

1. ข้อมูล Channel

  1. สร้าง LINE OA และเปิด Messaging API ที่ LINE Developers Console
  2. คัดลอก Channel secret (แท็บ Basic settings) และออก Channel access token (แท็บ Messaging API)
  3. ใส่ Webhook URL ด้านล่าง แล้วเปิด Use webhook

2. ส่งถึงใคร

ผู้รับ

3. ริชเมนูรายวัน

ปิดอยู่

ระบบสร้างริชเมนูใหม่ทุกวันตอนเที่ยงคืน แยกตามชั้นเรียน สีตามวัน มีวันที่และชื่อวัน และแสดง “พรุ่งนี้หยุด” เมื่อวันถัดไปเป็นวันหยุด เมื่อแก้ตาราง ชั้นเรียน หรือวันพิเศษ ระบบจะสร้างใหม่ให้อัตโนมัติ
