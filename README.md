# 📚 ตารางสอน + แจ้งเตือน LINE OA · v3.0

ระบบจัดตารางสอนที่ **แจ้งเตือนก่อนเริ่มคาบผ่าน LINE OA** เป็น Flex Message สวย ๆ พร้อม **ปุ่มนำทางไปห้องเรียน** (Google Maps)

## ✨ ความสามารถ

| | |
|---|---|
| 🎓 **หลายชั้นเรียน (ใหม่ v3.0)** | สร้าง ม./ห้อง ได้ทีละหลายห้อง ตารางสอนแยกตามห้อง (หรือใช้ร่วมทุกห้อง) แอดมินผูกบัญชี LINE หรือกลุ่ม LINE เข้ากับห้อง แล้วการแจ้งเตือน คำตอบ และริชเมนูจะเป็นของห้องนั้น |

## 🚀 เริ่มใช้งาน

```bash
npm install
npm start          # เปิด http://localhost:3000
```

ต้องใช้ Node.js 18.17 ขึ้นไป ข้อมูลจะเก็บในโฟลเดอร์ `data/` (ไม่ต้องติดตั้งฐานข้อมูล)

ตั้งค่าผ่านไฟล์ `.env` ได้ (ดูตัวอย่างใน `.env.example`):

| ตัวแปร | ความหมาย |
|---|---|
| `PORT` | พอร์ต (ค่าเริ่มต้น 3000) |
| `DATA_DIR` | โฟลเดอร์เก็บข้อมูลและฟอนต์ที่อัปโหลด |
| `ADMIN_PASSWORD` | ตั้งเพื่อล็อกหน้าแอดมินด้วยรหัสผ่าน (**ควรตั้งเมื่อนำขึ้นอินเทอร์เน็ต**) |
| `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_CHANNEL_SECRET` | ใส่ที่นี่หรือในหน้า LINE OA ของเว็บก็ได้ |
| `DATABASE_URL` | PostgreSQL connection string (ถ้าตั้งจะใช้ Postgres แทนไฟล์) |
| `ANTHROPIC_API_KEY` | คีย์สำหรับฟีเจอร์เพิ่มจากรูป (ใส่ในหน้าตั้งค่าแทนก็ได้) |
| `PUBLIC_URL` | URL สาธารณะ ใช้แสดง Webhook URL ที่ถูกต้องเมื่ออยู่หลัง proxy |

> โหลด `.env` ด้วย `node --env-file=.env server.js` (Node 20.6+) หรือกำหนดตัวแปรผ่านแพลตฟอร์มที่ deploy

## 💬 เชื่อมต่อ LINE OA

1. ไปที่ [LINE Developers Console](https://developers.line.biz/console/) แล้วสร้าง Provider และ **Messaging API channel** (หรือเปิด Messaging API ให้ LINE OA ที่มีอยู่)
2. ในแท็บ **Basic settings** ให้คัดลอก **Channel secret**
3. ในแท็บ **Messaging API** ให้กด Issue **Channel access token (long-lived)**
4. เปิดหน้า **LINE OA** ในเว็บนี้ วางค่าทั้งสอง แล้วกด **บันทึก** และ **ทดสอบการเชื่อมต่อ**
5. คัดลอก **Webhook URL** ไปใส่ในแท็บ Messaging API แล้วเปิด **Use webhook** (URL ต้องเป็น HTTPS)
6. ที่ LINE Official Account Manager ให้ปิด “ข้อความตอบกลับอัตโนมัติ” เพื่อไม่ให้ตอบซ้ำกับระบบ
7. ให้นักเรียนเพิ่มเพื่อน OA หรือเชิญบอทเข้ากลุ่มห้องเรียน แล้วผู้รับจะขึ้นในหน้า LINE OA อัตโนมัติ

**โหมดการส่ง**
- **Broadcast** ส่งถึงเพื่อนทุกคนของ OA (ไม่ส่งเข้ากลุ่ม)
- **เลือกผู้รับ** ส่งแบบ push ถึงคนหรือกลุ่มที่เปิดสวิตช์ไว้ เหมาะกับการส่งเข้ากลุ่ม LINE ของห้อง

> ทั้งสองแบบนับรวมในโควตาข้อความรายเดือนของแพ็กเกจ LINE OA ของคุณ

## 📷 เพิ่มตารางสอนจากรูป (v2.0)

1. สร้าง API Key ที่ [Anthropic Console](https://console.anthropic.com/settings/keys) แล้วใส่ในหน้า **ตั้งค่า → AI อ่านตารางจากรูป** (หรือตั้ง `ANTHROPIC_API_KEY`)
2. ไปที่หน้า **ตารางสอน** แล้วกด **📷 เพิ่มจากรูป** จากนั้นลากรูปมาวาง ถ่ายรูป หรือกด Ctrl+V
3. ใส่ข้อมูลเพิ่มเติมได้ถ้าจำเป็น เช่น “คาบ 1 เริ่ม 08:30 คาบละ 50 นาที” สำหรับตารางที่ระบุเป็นคาบ
4. กด **✨ อ่านตาราง** ระบบจะตรวจทุกคาบและแสดงสถานะ:
   - 🟢 **พร้อมเพิ่ม**: ข้อมูลครบ ไม่ซ้ำ ไม่ชน (ถ้าเปิด “เพิ่มอัตโนมัติ” จะเพิ่มทันที)
   - ♻️ **ซ้ำ**: มีวิชานี้ในวันและเวลาเดียวกันอยู่แล้ว
   - ⚠️ **เวลาชน**: ทับกับคาบที่มีอยู่ หรือทับกันเองในรูป
   - ✕ **ไม่ครบ**: ไม่มีชื่อวิชา ไม่รู้วัน หรือเวลาผิด (แก้ในตารางแล้วติ๊กเพื่อเพิ่มได้)
5. คาบที่เพิ่มจะเปิดแจ้งเตือน LINE ตามค่าเริ่มต้นทันที

ใช้โมเดล `claude-opus-5-5` แบบ structured output (บังคับให้ตอบเป็น JSON ตาม schema) และเบราว์เซอร์จะย่อรูปให้เหลือด้านยาวสุด 2000px ก่อนส่ง คิดค่าบริการตามการใช้งานของ Anthropic

## 🎓 หลายชั้นเรียน วันพิเศษ และริชเมนู (v3.0)

1. ไปที่ **ชั้นเรียน** กด **⚡ สร้างหลายห้อง** (เช่น ม.1–ม.6 ห้องละ 3 ห้อง)
2. ไปที่ **ตารางสอน** เลือกห้องที่มุมขวาบน แล้วเพิ่มคาบ หรือใช้ “เพิ่มจากรูป” ซึ่งเลือกห้องปลายทางได้ คาบที่เลือก “ใช้ร่วมทุกชั้นเรียน” เช่น เคารพธงชาติ จะแสดงในทุกห้อง
3. ให้นักเรียนเพิ่มเพื่อน OA หรือเชิญบอทเข้ากลุ่มห้อง แล้วที่หน้า **ชั้นเรียน** ส่วน “ผูกบัญชี LINE กับชั้นเรียน” ให้เลือกห้องให้แต่ละบัญชี
4. ไปที่ **LINE OA** แล้วเปิด **ริชเมนูรายวัน** ระบบจะสร้างเมนูของทุกห้องและผูกให้ผู้ใช้ทันที บัญชีที่ยังไม่ระบุห้องจะได้เมนูค่าเริ่มต้น
5. ไปที่ **วันพิเศษ** แล้วเพิ่มวันหยุดหรือช่วงปิดภาค ระบบจะ:
   - งดแจ้งเตือนคาบเรียนในวันนั้น (วันกิจกรรมเลือกได้ว่าจะงดหรือไม่)
   - แสดงแถบ “พรุ่งนี้หยุด” บนริชเมนูในวันก่อนหน้า และ “วันนี้หยุดเรียน” พร้อมวันเปิดเรียน
   - ส่งประกาศถึงทั้งโรงเรียนทุกวันเวลา 08:00 ตลอดช่วงหยุด (เปลี่ยนเวลาและเปิดแจ้งล่วงหน้า 1 วันได้)

> ริชเมนูผูกได้เฉพาะบัญชีผู้ใช้ (LINE ไม่มีริชเมนูในแชทกลุ่ม) ส่วนกลุ่ม LINE ของห้องยังได้รับแจ้งเตือนและพิมพ์คำสั่งได้ตามปกติ
> ฟอนต์บนริชเมนูคือ Prompt (SIL Open Font License) อยู่ใน `assets/fonts`

## ⏱️ ระบบแจ้งเตือนทำงานอย่างไร

- ตรวจทุก 20 วินาทีตามโซนเวลาที่ตั้งไว้ (ค่าเริ่มต้น `Asia/Bangkok`)
- แต่ละคาบจะแจ้ง **1 ครั้งต่อวัน** เมื่อถึงเวลา `เวลาเริ่ม − จำนวนนาทีที่ตั้ง` (รองรับการแจ้งข้ามเที่ยงคืน)
- ถ้าเซิร์ฟเวอร์ดับ ระบบจะส่งย้อนหลังให้ได้ไม่เกิน 5 นาที
- ถ้าแก้เวลาของคาบ ระบบจะแจ้งเตือนตามเวลาใหม่ได้อีกครั้ง
- ประวัติการส่งดูได้ที่หน้า **ภาพรวม**

## ☁️ Deploy

เซิร์ฟเวอร์ต้องทำงานตลอดเวลาเพื่อให้ส่งแจ้งเตือนได้ตรงเวลา และต้องเก็บข้อมูลไว้ถาวร ระบบรองรับ 2 แบบ:
- ถ้ากำหนด `DATABASE_URL` จะเก็บข้อมูลและฟอนต์ที่อัปโหลดใน **PostgreSQL**
- ถ้าไม่กำหนด จะเก็บเป็นไฟล์ใน `DATA_DIR`

### Render (แพ็กเกจฟรี)

`render.yaml` ตั้งค่าไว้สำหรับแพ็กเกจฟรีแล้ว ได้แก่ Web Service ฟรี + Postgres ฟรี ที่ region สิงคโปร์ และสุ่ม `ADMIN_PASSWORD` ให้อัตโนมัติ

ข้อจำกัดของแพ็กเกจฟรีที่ระบบรองรับไว้แล้ว:
- **Web Service หลับเมื่อไม่มีคนเข้า 15 นาที** ทำให้แจ้งเตือนหยุด ระบบจึงปิงตัวเองทุก 10 นาทีผ่าน `RENDER_EXTERNAL_URL` (ปิดได้ด้วย `KEEP_ALIVE=false`) เพื่อความชัวร์แนะนำให้ตั้ง [UptimeRobot](https://uptimerobot.com) หรือ [cron-job.org](https://cron-job.org) ให้เรียก `https://<ชื่อแอป>.onrender.com/healthz` ทุก 5 นาทีด้วย ซึ่งจะช่วยปลุกระบบกลับมาหลัง restart
- **ไม่มีดิสก์ถาวร** ระบบจึงใช้ Postgres แทน
- **Postgres ฟรีของ Render หมดอายุใน 30 วัน** ก่อนหมดอายุให้อัปเกรด หรือย้ายไปใช้ Postgres ฟรีที่ไม่หมดอายุ เช่น [Neon](https://neon.tech) หรือ [Supabase](https://supabase.com) โดยกด “ส่งออก” ข้อมูลในหน้าตั้งค่า แล้วเปลี่ยน `DATABASE_URL` เป็นของที่ใหม่ จากนั้นกด “นำเข้า” ข้อมูลกลับเข้าไป (ต้องตั้งค่า LINE และฟอนต์ใหม่)
- Web Service ฟรีใช้ได้ 750 ชั่วโมงต่อเดือน ซึ่งพอสำหรับ 1 แอปที่เปิดตลอดเดือน

### ที่อื่น ๆ
- **VPS / เครื่องในโรงเรียน**: `npm ci --omit=dev && npm start` ร่วมกับ pm2 หรือ systemd แล้วใช้ Caddy, Nginx หรือ Cloudflare Tunnel เพื่อให้ได้ HTTPS
- **ทดสอบบนเครื่อง**: ใช้ `ngrok http 3000` เพื่อให้ได้ HTTPS URL สำหรับ webhook
